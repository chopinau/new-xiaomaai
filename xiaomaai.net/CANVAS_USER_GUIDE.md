## 一、页面概览

### 简介

**小马AI画布** 是一个基于浏览器的 AI 图像创作工作台，核心特性：

- 🎨 **无限画布**：自由拖拽、缩放、连接节点
- 🔗 **可视化工作流**：通过连接不同类型的节点，构建复杂的 AI 处理流程
- 🖼️ **多模型支持**：豆包、GPT Image 1.5、Nano Banana Pro 等 500+ 模型
- 💾 **本地保存**：配置和工作流保存在浏览器本地
- 🎯 **一站式创作**：从需求到成品，无需切换工具

### 主要功能模块

| 模块 | 说明 |
|------|------|
| 图片生成 | 文生图、参考图、批量生图 |
| 反推 | AI 分析图片，生成提示词 |
| 产品资料 | 编辑商品信息 |
| 分层渲染 | 将图片按区域拆分为多层 |
| 详情页 | 生成电商详情页分屏 |
| 换装 | 服装虚拟试穿 |
| 电影 | 生成电影分镜/短视频脚本 |

### 访问地址

- 本地开发：http://localhost:3000/canvas
- 生产环境：https://xiaomaai.net/canvas

## 二、快速开始

### 1. 配置 API

**步骤 1**：进入 `/canvas` 页面

打开浏览器访问 `http://localhost:3000/canvas`，将看到配置页面。

**步骤 2**：查看默认地址

「生图模型基址」输入框已预置为 `小马AI默认地址`（实际为 `https://api.lk888.ai/api`）。

**步骤 3**：填写 API Key

在「生图 API Key」输入框中填写你的 API Key。

> 💡 **获取 API Key**：扫描页面内的客服二维码，联系客服获取。

**步骤 4**：测试连接

点击「测试生图连接」按钮，系统会：
- 验证 API Key 有效性
- 获取可用模型列表
- 弹出「连接成功」提示

**步骤 5**：选择生图模型

测试成功后，会出现「生图模型」下拉框，从中选择你想使用的模型：
- 豆包系列（推荐）
- GPT Image 1.5（高级）
- Nano Banana Pro（高级）

**步骤 6**：（可选）配置文本模型

点击「反推/智能体文本模型」展开，配置：
- 文本模型基址（默认沿用生图基址）
- 文本模型 API Key（默认沿用生图 Key）
- 点击「检测文本模型」验证

**步骤 7**：进入画布

点击「进入新版画布」按钮，开始使用。

### 2. 预设管理

方便在多个 API 配置之间快速切换：

- **保存预设**：点击「保存」按钮，输入预设名称（如"工作账号"、"测试账号"）
- **切换预设**：在「选择预设」下拉框中选择
- **删除预设**：选择预设后点击「删除」

### 3. 记住配置

默认勾选「记住配置到本机」，配置将保存在浏览器 localStorage 中，下次访问自动加载。

## 三、画布基础操作

### 1. 视图控制

| 操作 | 功能 |
|------|------|
| 鼠标滚轮 | 缩放画布 |
| 左键拖拽空白处 | 平移画布 |
| `+` / `-` 按钮 | 放大/缩小 |
| `适配` 按钮 | 自动调整视图，完整显示所有节点 |
| `整理` 按钮 | 自动排列所有节点 |
| `编组` 按钮 | 将选中的多个节点编为一组 |

### 2. 节点操作

#### 添加节点

在画布空白处**右键**，弹出菜单：

```
┌─────────────────┐
│ 添加反推         │
│ 添加产品资料     │
│ 添加分层渲染     │
│ 添加详情页       │
│ 添加换装         │
│ 添加电影         │
│ 添加生图         │
└─────────────────┘
```

选择节点类型后，会在点击位置创建新节点。

#### 移动节点

- **左键按住节点** → 拖拽到目标位置
- 节点会实时跟随鼠标移动

#### 选择节点

- **单击节点**：选中单个节点
- **空白处拖拽**：框选多个节点
- **Ctrl + 单击**：多选切换

#### 删除节点

- 选中节点 → 按 `Delete` 或 `Backspace` 键

#### 复制/粘贴

- `Ctrl + C` 复制选中的节点
- `Ctrl + V` 在画布中心粘贴

### 3. 顶部工具栏

| 按钮 | 功能 |
|------|------|
| **配置** | 返回配置页（修改 API Key、模型） |
| **详情页预览** | 打开详情页分屏预览面板 |
| **图库** | 打开提示词图库（保存/复用好图） |
| **日志** | 打开软件日志（API 请求、错误） |
| **清空 v2** | 清空整个画布（不可恢复！） |

### 4. 节点连接

#### 连接方式

- 每个节点**右侧**有一个输出端口（圆点）
- 每个节点**左侧**有一个输入端口（圆点）
- **从输出端口拖拽到另一个节点的输入端口**，即可连接

#### 连接规则

- 一对一：一个输入端口只能连接一个输出
- 一对多：一个输出端口可以连接到多个输入
- 顺序执行：数据从上游流向下游

#### 断开连接

- **右键点击连线** → 选择「断开」

### 5. 小地图

右下角的小地图：
- 显示整个画布的全貌
- 红色框表示当前可视区域
- **点击或拖动**小地图，快速跳转到对应位置

### 6. 关闭保护

如果有关闭页面时有节点还在生成中：
- 会弹出「图片还在生成中」提示
- 选择「继续等待」：保持页面，等待完成
- 选择「仍然关闭」：强制关闭（可能丢失结果，**费用已扣**）

## 四、右键菜单节点类型详解

右键画布空白处，可以看到 **7 种节点类型**。每种节点都有独特的功能和用途。

### 1. 添加生图（generate）⭐ 最常用

**功能**：根据文本提示词生成图片，是整个画布最核心的节点。

**支持模型**：
- 豆包系列（doubao-seed-2-pro 等）
- GPT Image 1.5
- Nano Banana Pro
- 其他 500+ 模型

**可配参数**：
- **模型**：选择生图模型
- **尺寸**：512x512、1024x1024、2048x1152 等
- **质量**：standard / high
- **格式**：png / jpeg / webp
- **生成数量 n**：1-4 张
- **参考图模式**：单图 / 多图 / 无参考

**使用场景**：
- 快速文生图
- 参考图生图（图生图）
- 批量生图（一次 4 张）

**工作流位置**：通常是工作流的**核心节点**，上游可连接反推、产品资料，下游可连接分层渲染、详情页。

**示例**：
```
提示词：一只可爱的橘猫坐在窗台上，阳光透过窗帘，温馨氛围，4K 高清
模型：doubao-seed-2-0-pro-260215
尺寸：1024x1024
质量：high
```

---

### 2. 添加反推（text）

**功能**：使用文本模型（GPT/Claude/Gemini 等）分析图片，反推提示词或回答问题。

**支持模型**：
- GPT 系列（gpt-5.5、gpt-5.4-mini、gpt-image-1.5 等）
- Claude 系列（claude-sonnet-5、claude-opus-4.8）
- Gemini 系列（gemini-3.5-flash、gemini-3.1-pro）
- 其他文本模型（DeepSeek-V4、Kimi K2.6、Qwen3-Max 等）

**使用场景**：
- 上传参考图，AI 反推可能的提示词
- AI 智能问答（产品咨询、创意建议）
- 提示词优化（让 AI 改进你的提示词）

**特殊功能**：
- 智能体对话：像 ChatGPT 一样多轮对话
- 引用反推结果：反推的提示词可直接拖拽到生图节点

**工作流位置**：
- 上游：可连接生图节点（接收图片）
- 下游：可连接生图节点（输出提示词）

**典型工作流**：
```
[参考图] → [反推] → [生图]
```

---

### 3. 添加产品资料（detail）

**功能**：编辑结构化的产品资料信息。

**可编辑字段**：
- 标题
- 卖点
- 规格参数
- 价格
- 详细描述
- 关键词

**使用场景**：
- 为详情页提供产品信息
- 多 SKU 资料管理
- 营销文案准备

**工作流位置**：
- 下游：连接到「详情页」节点，自动填充到详情页

---

### 4. 添加分层渲染（sketch）

**功能**：将一张图片按区域拆分为多个独立图层，方便精准编辑。

**操作流程**：
1. 连接上游「生图」节点的输出
2. 在画布上拖动鼠标框选要分离的区域
3. 点击「保存聚焦」
4. AI 会自动将选中区域分离为独立图层

**使用场景**：
- 产品图分层（背景/产品/装饰）
- 局部重绘（只改一个元素）
- 精准编辑（不破坏其他部分）

**工作流位置**：
- 上游：必须连接「生图」节点

---

### 5. 添加详情页（detailPage）

**功能**：基于多张图片自动生成电商详情页分屏（淘宝/京东/拼多多风格）。

**输出形式**：
- 多张连续分屏图
- 自动排列为详情页布局
- 支持预览和导出

**使用场景**：
- 淘宝/京东详情页制作
- 拼多多详情页
- 跨境电商 listing 配图

**工作流位置**：
- 上游：连接「产品资料」（提供信息）和多个「生图」节点（提供图片）

**典型工作流**：
```
[产品资料] ─────→ [详情页]
[生图1] ─────────→ [详情页]
[生图2] ─────────→ [详情页]
[生图3] ─────────→ [详情页]
```

**预览**：点击顶部「详情页预览」按钮查看完整分屏效果。

---

### 6. 添加换装（tryOn）

**功能**：将服装图片"穿"到人像图片上，实现虚拟试穿。

**操作流程**：
1. 连接「商品图」到换装节点的商品输入端口
2. 连接「模特图」到换装节点的模特输入端口
3. 点击「生成」

**使用场景**：
- 服装电商展示
- 虚拟试穿
- 模特换装预览

**工作流位置**：
- 上游：必须连接两个输入（商品图 + 模特图）

**典型工作流**：
```
[商品图] ──→ [换装] ←── [模特图]
              ↓
           [生成结果]
```

---

### 7. 添加电影（cinema）

**功能**：基于多张图片生成电影分镜或短视频脚本。

**可配置参数**：
- **模式**：真人（live-action）/ 动漫（anime）/ 商业（commerce）/ 自动（auto）
- **角色分配**：每张图片分配角色（subject/subject/scene/style/camera）
- **结构化字段**：场景、动作、台词、音效
- **自检项**：自动检查分镜质量

**使用场景**：
- 短视频脚本（抖音/快手）
- 商品视频脚本
- 广告分镜
- MV 分镜

**工作流位置**：
- 上游：可连接多张「生图」节点的输出作为分镜素材

**典型工作流**：
```
[场景图1] ──→ [电影] ──→ [分镜脚本]
[场景图2] ──→ [电影]
[场景图3] ──→ [电影]
```

## 五、节点连接与工作流

### 工作流设计原则

1. **数据流向**：从左到右，从上到下
2. **最小可行**：先跑通最简单的流程，再逐步添加节点
3. **复用节点**：一个输出可以连接多个输入
4. **版本管理**：生图节点支持多版本，可对比效果

### 常用工作流模板

#### 模板 1：产品图生成

```
[反推（产品图）] → [生图（产品图）] → [分层渲染] → [详情页]
                                      ↓
                              [保存到图库]
```

#### 模板 2：服装换装展示

```
[模特图] ────→ [换装] ←──── [商品图]
                ↓
            [生成结果图]
```

#### 模板 3：详情页制作

```
[产品资料] ──→ [详情页]
[生图1] ──────→ [详情页]
[生图2] ──────→ [详情页]
[生图3] ──────→ [详情页]
[生图4] ──────→ [详情页]
```

#### 模板 4：短视频脚本

```
[场景图1] ──→ [电影] ──→ [分镜脚本]
[场景图2] ──→ [电影]
[场景图3] ──→ [电影]
[角色图1] ──→ [电影]
```

#### 模板 5：反推生图

```
[反推（参考图）] → [生图] → [保存]
```

### 节点连接图示

```
[节点A] ──→ [节点B] ──→ [节点C]
   ↓           ↓           ↓
  输出        处理        输出
```

## 六、实用功能

### 1. 提示词图库

**用途**：保存生成的好图和工作流，方便后续复用。

**使用方法**：
1. 在生图节点上点击「加入图库」
2. 提示词和工作流配置会一并保存
3. 在「图库」面板查看所有保存的内容
4. 拖拽到画布可一键复用

**应用场景**：
- 收藏好用的提示词模板
- 复用成功的工作流配置
- 团队内部共享创作经验

### 2. 预设配置

**用途**：保存多个 API 配置（不同 Key、不同模型）。

**使用场景**：
- 多个 API 账号
- 不同的模型组合
- 工作和个人账号分离

**操作**：
- 点击「保存」按钮，输入预设名称
- 在「选择预设」下拉框切换

### 3. 软件日志

**用途**：记录所有 API 请求、错误、性能数据。

**查看方式**：
- 顶部「日志」按钮
- 可以看到：
  - 每次 API 请求的 URL、参数、响应时间
  - 错误信息和堆栈
  - 用户操作记录

**应用场景**：
- 排查 API 调用问题
- 优化性能
- 复现 Bug

### 4. 节点版本管理

生图节点支持**多版本**：
- 每次生成都保存为新版本
- 可以对比不同生成结果
- 切换到任意历史版本
- 删除不需要的版本

### 5. 画布持久化

- 所有节点、连接、配置自动保存到浏览器
- 刷新页面不会丢失
- 清除浏览器数据会重置

### 6. 缩略图与预览

- 点击生图节点的图片 → 打开大图预览
- 预览界面可下载、切换图片
- 支持键盘左右键翻页

## 七、常见问题

### Q1：提示"接口返回为空：未找到有效的图片数据"？

**原因**：
- API Key 无效
- 账户余额不足
- 模型不支持
- 网络问题

**解决方法**：
1. 检查 API Key 是否正确
2. 检查账户余额
3. 尝试切换到其他模型（如豆包系列）
4. 查看「日志」面板，查看详细错误

### Q2：GPT Image 1.5 / Nano Banana Pro 选不了？

**原因**：
- 这是**异步任务模型**，需要后端支持
- 小马AI 默认地址会自动识别

**解决方法**：
- 选择这两个模型后，提交任务会进入轮询模式
- 等待 10-60 秒，图片会自动显示
- 如余额不足，需先充值

### Q3：画布卡顿？

**原因**：
- 节点数量太多
- 浏览器内存不足
- 图片太大

**解决方法**：
- 使用「整理」按钮重新排列
- 删除不需要的节点
- 分组管理（多选后「编组」）
- 清理浏览器缓存

### Q4：配置丢失？

**原因**：
- 未勾选「记住配置到本机」
- 浏览器清除了 localStorage
- 切换了浏览器/设备

**解决方法**：
- 重新配置
- 使用「预设」功能保存多份配置
- 预设名称会显示在选择框中

### Q5：反推节点没有反应？

**原因**：
- 未配置文本模型
- 文本模型 Key 无效
- 上游无图片输入

**解决方法**：
- 展开「反推/智能体文本模型」进行配置
- 点击「检测文本模型」验证
- 确认上游节点已连接

### Q6：怎么下载生成的图片？

**方法 1**：点击图片打开预览，点击「下载保存」按钮
**方法 2**：右键图片 → 「图片另存为」

### Q7：可以批量导出所有节点图片吗？

暂不支持批量导出，可以：
- 逐个点击下载
- 使用「图库」功能集中管理

### Q8：节点连接错了怎么断开？

**方法 1**：右键点击连线 → 选择「断开」
**方法 2**：拖动连线到空白处

## 八、最佳实践

### 1. 从简单开始

- 第一次使用，先添加一个「生图」节点体验
- 熟悉后再添加反推、分层等高级功能
- 复杂工作流可分步骤搭建

### 2. 善用反推

- 上传参考图反推提示词
- 让 AI 优化你的提示词
- 反推结果可直接拖到生图节点

### 3. 保存预设

- 不同 API Key 保存为不同预设
- 不同模型组合保存为预设
- 一键切换，提高效率

### 4. 加入图库

- 好用的提示词加入图库
- 成功的工作流加入图库
- 后续一键复用

### 5. 查看日志

- 出问题先看日志
- 日志包含详细错误信息
- 复现 Bug 时查看请求参数

### 6. 善用版本

- 生图节点自动保存多版本
- 对比不同生成结果
