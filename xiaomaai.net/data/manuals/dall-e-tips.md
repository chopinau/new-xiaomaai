# DALL·E 3 提示词技巧

DALL·E 3 是 OpenAI 的图像生成模型,以理解力强著称。

## 产品介绍

DALL·E 3 的优势:
- 📝 **自然语言理解**:不需记参数
- 🔤 **文字渲染**:能写出清晰可读的文字
- 🎨 **细节把控**:复杂描述也能实现

## 5 个实战案例

### 案例 1:信息图
**提示词**:
```
设计一张信息图,主题是"全球咖啡消费量 Top 10 国家",
柱状图形式,深蓝色背景,白色文字,简洁现代
```

### 案例 2:UI 设计
**提示词**:
```
一个 iOS App 的主界面设计,类似 Todoist,
深色模式,顶栏 + 任务列表 + 底部 Tab Bar
```

### 案例 3:插画
**提示词**:
```
一幅插画,主题"科技与人文",赛博朋克风格,
包含电路图案和书法元素,暖色调
```

### 案例 4:Logo
**提示词**:
```
一个咖啡店的 Logo,主元素是一杯咖啡,
手绘风格,主色棕色和米色,简洁
```

### 案例 5:漫画
**提示词**:
```
一张 4 格漫画,关于"程序员的日常",
幽默风格,黑白线条,适合社交媒体分享
```

## 进阶玩法

### 1. 指定构图
明确指定视角和构图:
```
鸟瞰视角 / 仰视 / 45 度 / 中心对称
```

### 2. 引用艺术家
```
类似 [艺术家名] 的风格,但要避免完全复制
```

### 3. 限制元素
```
只使用 3 种颜色:黑、白、红
```

## 提示词合集

```text
1. 头像: "一个 [风格] 风格的头像,[人物描述],[背景描述]"
2. 海报: "一张 [主题] 海报,主色 [色],[文字] 用 [字体]"
3. 插图: "为 [受众] 设计的插图,关于 [主题],[风格] 风格"
4. 产品图: "一张产品图,展示 [产品],[角度] 视角,[背景]"
5. 漫画: "一个 [主题] 的 4 格漫画,幽默风格"
```
