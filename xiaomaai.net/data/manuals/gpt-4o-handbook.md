# GPT-4o 图像生成完全手册

GPT-4o 是 OpenAI 推出的原生多模态大模型,内置图像生成能力,无需切换到 DALL·E 即可直接对话出图。

## 产品介绍

GPT-4o 的图像生成是**原生集成**的,相比 DALL·E 3:
- ✅ 上下文理解更强(对话中直接引用)
- ✅ 文字渲染能力大幅提升
- ❌ 分辨率上限较低(1024×1024)
- ❌ 风格控制不如 Midjourney 精细

## 5 个实战案例

### 案例 1:产品海报
**提示词**:
```
为一款"无糖气泡水"设计一张夏日海报,主体是透明瓶身 + 柠檬切片,
背景是渐变蓝绿色,字体使用粗体中文"0 糖 0 卡",海报比例 9:16,
适合小红书发布。
```

### 案例 2:小红书爆款封面
**提示词**:
```
生成一张小红书封面,主题"打工人早餐",画面是 3 个早餐摆盘(咖啡 + 
可颂 + 沙拉),俯拍视角,暖色调,文字框留白位置在画面左下角。
```

### 案例 3:教育插图
**提示词**:
```
画一张示意图解释"光合作用",适合 6 岁孩子理解,卡通风格,
包含太阳、植物、二氧化碳、氧气等元素,带中文标签。
```

### 案例 4:产品对比图
**提示词**:
```
生成一张"iPhone 16 vs iPhone 15"对比图,两台手机并排,
左边贴绿色"NEW"标签,右边贴红色"OLD"标签,白色背景。
```

### 案例 5:表情包
**提示词**:
```
画一只戴着眼镜的猫,正在看电脑,表情呆萌,适合做微信表情包,
圆形构图,白底,线条清晰。
```

## 进阶玩法

### 1. 多轮迭代出图
不要一次就想要完美结果。先让 GPT-4o 出初稿,然后对话式调整:
> "把背景换成深蓝色"、"字体加粗"、"柠檬切片再大一些"

### 2. 风格迁移
输入一张参考图,让 GPT-4o 模仿其风格:
> "按这张图的画风,重新画一个'海边日落'"

### 3. 文字精确控制
GPT-4o 的文字渲染比 DALL·E 3 更准:
> "画面中央写'开业大吉'四个红色宋体大字"

## 提示词合集

```text
1. 电商主图: "为 [产品] 设计 [平台] 主图,突出 [卖点],颜色 [色系]"
2. 头像: "画一个 [风格] 风格的头像,角色 [描述],适合 [场景]"
3. Logo: "设计一个 [行业] 品牌 Logo,主色 [色],字体 [风格],简洁"
4. 配图: "为文章'[标题]'配一张 [风格] 风格插图,内容是 [要点]"
5. 海报: "生成一张 [节日] 海报,主体 [元素],文字 '[文案]'"
```

## 注意事项

⚠️ **商业使用**:OpenAI 允许商业用途,但需遵守 [Usage Policies](https://openai.com/policies/usage-policies)

⚠️ **版权风险**:避免生成特定艺术家风格(如"画成宫崎骏风格")

⚠️ **真人形象**:不生成公众人物,避免肖像权纠纷
