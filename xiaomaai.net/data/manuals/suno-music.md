# Suno AI 音乐创作教程

Suno 是当前最火的 AI 音乐生成工具,普通人也能 30 秒生成完整歌曲。

## 产品介绍

Suno 的优势:
- 🎵 **30 秒生成完整歌曲**(含人声)
- 🎤 **支持中文歌词**
- 🎸 **多种风格**:流行、摇滚、电子、古典
- 💰 **免费版每天 10 首**

## 5 个实战案例

### 案例 1:中文流行
**提示词**:
```
一首中文流行歌曲,关于"异乡人的思乡",
温暖的女声,钢琴伴奏,中速,B 段有弦乐
```

### 案例 2:儿童歌曲
**提示词**:
```
一首儿歌,关于"小动物们去春游",
可爱的童声,欢快的节奏,简单的歌词
```

### 案例 3:电子舞曲
**提示词**:
```
一首 EDM 舞曲,128 BPM,适合夜店,
合成器音色,带 drop 段
```

### 案例 4:古风歌曲
**提示词**:
```
一首古风歌曲,关于"江湖侠客",
古筝+箫伴奏,男声,豪迈风格
```

### 案例 5:广告背景音乐
**提示词**:
```
一段 30 秒的背景音乐,适合咖啡店广告,
温暖,治愈,带轻微的 lo-fi 感
```

## 进阶玩法

### 1. 自定义歌词
使用 `[Verse]`, `[Chorus]`, `[Bridge]` 等标签:
```
[Verse]
月光洒在窗前
我想起远方的你

[Chorus]
回来吧,我在这里等
```

### 2. 风格混搭
结合多种风格:
```
一首民谣+电子的混合歌曲
```

### 3. 延长歌曲
点击"Extend"按钮,基于已生成部分继续创作
